# Financial Consumer Complaints Analysis

## Overview
Analyzed 62,516 real-world CFPB financial 
consumer complaints (2017–2023) to uncover 
trends, patterns & business insights.

## Tools Used
Python | Pandas | NumPy | Matplotlib | 
Seaborn | Power BI | DAX | Power Query

## Key Findings
-  Complaints grew **140%** in 5 years
-  Top 2 products = **65.6%** of all complaints
-  **1 in 4** consumers got monetary relief
-  **93.8%** complaints resolved on time
-  California = **21.9%** of all complaints

## Project Structure
- Data Cleaning & EDA (Python/Jupyter)
- Feature Engineering (6+ new features)
- DAX Measures (7 KPIs)
- Interactive Power BI Dashboard
